PROJECT FOCUS — MOBILE WEB APP PROTOTYPE (v0.1)

This is a mobile-first installable-web-app prototype, not a native APK yet.
It currently includes:
- Focus timer with 15/25/45/60-minute presets
- Start, pause and reset
- Subject selection
- Completed session history saved on this device
- Daily study minutes, daily sessions and total sessions
- Light/dark appearance toggle
- Basic offline caching after first load

No ads, accounts, subscriptions, payments or external services.

HOW TO TRY IT ON ANDROID:
1. Extract this ZIP.
2. Upload the files to a free static host that supports HTTPS, such as GitHub Pages.
3. Open the published HTTPS address in Chrome on your Android phone.
4. Chrome menu (three dots) > Add to Home screen / Install app.

IMPORTANT:
- This prototype does NOT block other apps, websites, YouTube, Reels or Shorts.
- A web app cannot reliably implement Android-wide app blocking. That requires a native Android app, user-granted permissions and careful compatibility testing.
- The timer may not continue accurately if the browser is suspended. Background-safe native timing and notifications are future work.
- All session history is stored locally in this browser on this device.

NEXT NATIVE ANDROID STEP:
